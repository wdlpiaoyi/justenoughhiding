# Just Enough Hiding (JEH)

> 中文: [README.md](README.md)

A **client-side** Minecraft Forge 1.20.1 mod that records *who* hides JEI/EMI content and *why*,
reveals what was hidden, and lets you hide content from the recipe viewer with your own local list
— handy for modpack authors who want one place to manage recipe-viewer visibility.

- Recipe viewer (optional, either one): [JEI](https://www.curseforge.com/minecraft/mc-mods/jei) or
  [EMI](https://www.curseforge.com/minecraft/mc-mods/emi). When both are installed **EMI wins**
  (JEH's UI/icons use EMI, while JEI-side reveal and intent recording still run); with neither
  installed the mod does nothing.
- Optional integration: [KubeJS](https://kubejs.com/) (read/write the hide list from scripts)
- License: MIT

## Features

- **Reveal**: on viewer startup, show ingredients hidden by tags / edit mode / the blacklist again;
  restore ingredients that were removed or missing; unhide hidden recipes and recipe categories.
- **Intent recording**: record hide/show actions performed by other mods, the viewer itself, the
  server, etc., with a viewer UI (source, count, time, ...).
- **ListEHiding**: your own hide list; JEHide hides matching content from the viewer. Supports
  multi-select / toggle / delete.
- **Types & matching**: all viewer ingredient types (items, fluids, chemicals, ...), recipes,
  recipe categories, tags, and wildcards / regex.
- **Unified management**: JEHide also treats recorded hide-intents as hide rules, i.e. effectively
  "reveal first, then re-hide from your list + intents".

## EMI support

- **UI/icons**: with EMI as the viewer, the intent viewer and hide list use EMI's index and icons.
  JEI-created entries (different type-uid spelling) also render correctly.
- **Reveal**: on EMI startup/reload, content hidden by tags (`c:hidden_from_recipe_viewers`), plugin
  removals (`removeEmiStacks`/`removeRecipes`), EMI edit mode, and the data-pack files
  `assets/emi/index/stacks` and `assets/emi/recipe/filters` is revealed (controlled by
  `[reveal] enabled`).
- **Hide**: the `[jehide]` list + intents apply as EMI predicates at bake time, taking precedence
  over reveal.
- **Recording**: EMI plugin removals (source = the calling mod), EMI edit mode (source
  `EMI edit mode`), and `emi:index_stacks` / `emi:recipe_filters` data (source = the **resource
  pack** providing the file).
- **Editing EMI data**: these files are **client resources** (`assets/emi/...`). After editing, use
  **F3+T** (reload resources) or toggle the resource pack — `/reload` only reloads server data
  (tags/recipes), not `assets/`.
- **Known limits**: EMI data shipped by mods shows as `mod_resources` (Forge merges mod resources,
  so the exact modid is unavailable); EMI has no category-hide API (`recipe_category` can only hide
  its recipes); the JEI bookmark key is not supported with EMI.

## Config files (`config/jeh/`)

| File | Description |
| --- | --- |
| `client.toml` | Mod settings (below); generated by Forge on first run |
| `listehiding.json` | Hide list; a **default list is generated on first run** (below) |
| `intentoverrides.json` | Per-intent apply/ignore flags (written by the GUI's Enable/Disable) |

> The generated `listehiding.json` ships a few `note="default"` entries and doubles as a format
> example:
> - armor-trim smithing recipes (`pattern`, scope `recipe`, `*_armor_trim_smithing_template`),
>   **enabled**;
> - disguise plates (AE2 `ae2:facade`, Create `create:copycat_panel`, Refined Storage
>   `refinedstorage:cover`), **disabled** by default; set `enabled` to `true` to use them.
>
> Modpack authors can copy the repo's `defaultconfigs/jeh/client.toml` into the instance's
> `defaultconfigs/jeh/`; Forge applies it on the first run of a new instance.

Main `client.toml` options:

```toml
[intentRecording]
enabled = true      # record intents

[reveal]
enabled = true      # reveal hidden content on startup

[jehide]
enabled = true      # hide per listehiding (+ intents)
applyIntents = true # also treat recorded hide-intents as hide rules

[intentView]
sortModes = ["source,kind,target", "kind,source,target", "target", "count:desc", "sequence"]
bookmarkTarget = "ICON" # bookmark key applies to ICON or ROW
```

## `listehiding.json` format

The root object is `{ "entries": [ ... ] }`. Each entry needs at least `kind`; `enabled` (default
`true`), `note`, and `priority` (default `0`) are optional.

```json
{
  "entries": [
    { "kind": "ingredient", "typeUid": "minecraft:item_stack", "uid": "minecraft:stone", "enabled": true, "note": "", "priority": 0 },
    { "kind": "tag", "tag": "minecraft:logs", "enabled": true },
    { "kind": "recipe", "recipeType": "minecraft:crafting", "recipeId": "minecraft:stick", "enabled": true },
    { "kind": "recipe_category", "recipeType": "minecraft:crafting", "enabled": true },
    { "kind": "pattern", "scope": "recipe_category", "pattern": "minecraft:*", "mode": "glob", "enabled": true },
    { "kind": "pattern", "scope": "", "pattern": "^minecraft:.*_ore$", "mode": "regex", "enabled": true },
    { "kind": "unset", "enabled": true }
  ]
}
```

- `kind = "ingredient"`: `typeUid` is the viewer ingredient type uid (e.g. `minecraft:item_stack`,
  `fluid_stack`, a chemical type); `uid` is that type's unique id.
- `kind = "tag"`: `tag` is the tag id (without `#`).
- `kind = "recipe"` / `"recipe_category"`: `recipeType` is the recipe type, `recipeId` the recipe id.
- `kind = "pattern"`: `scope` is the editor kind key (`""` = any, `ingredient|<typeUid>`, `recipe`,
  `recipe_category`, `tag`), `pattern` is the body, `mode` is `glob` or `regex`.
- `kind = "unset"`: empty placeholder (an empty editor field).

## In-game usage

Commands:

- `/jeh intents`: open the intent viewer
- `/jeh list`: open the hide-list editor

Keys (unbound by default): `key.justenoughhiding.open_intents`, `key.justenoughhiding.open_list`.

**Hide-list editor** (`/jeh list`):

- `New Entry` adds a blank entry; `Save` writes to disk and re-applies immediately; `Refresh`
  needs two clicks (discards in-memory changes and re-reads the file).
- Search box + type / status / sort dropdowns; `Desc` reverses the sort.
- Double-click a cell to edit **target** / **priority** / **note** inline.
- Right-click menu: Enable/Disable, Edit target / note / priority, Delete (confirmation).
- Multi-select: `Ctrl` toggles rows, `Shift` selects a range; right-click for batch
  Enable / Disable / Delete (delete needs three clicks).
- Grey rows come from intents: read-only, only Enable/Disable; the note shows the source (e.g.
  `intent + malum`). With JEI edit mode on, edit-mode intents are paused and marked
  `(edit mode paused)`.

**Editing a target**: the editor takes only an id; pick the type with the top tabs (`Auto` detects
item / tag / wildcard / recipe / category).

- `Auto` + `minecraft:*` → wildcard (glob); `?` matches a single character.
- A leading `~` is regex, e.g. `~^minecraft:.*_ore$`.
- A leading `#` is a tag, e.g. `#minecraft:logs`.
- You can also force the type with the `item` / `recipe` / `category` prefixes.

## KubeJS integration

Put scripts in `kubejs/client_scripts/` and use the global `JEH` object:

```js
// auto-detect (item / #tag / wildcard / recipe / category)
JEH.add('minecraft:stone')
JEH.add('#minecraft:logs')
JEH.add('minecraft:*')

// explicit
JEH.addItem('minecraft:stone')
JEH.addTag('minecraft:logs')
JEH.addPattern('minecraft:*')
JEH.addRecipe('minecraft:crafting', 'minecraft:stick')
JEH.addCategory('minecraft:crafting')

// note / priority (optional args)
JEH.add('minecraft:diamond', 'my note', 10)

// edit
JEH.remove('minecraft:stone')      // returns the number removed
JEH.setEnabled('minecraft:stone', false)
JEH.clear()
JEH.size()
JEH.list()

// persist and apply
JEH.save()    // writes listehiding.json; without it, changes are in-memory only
JEH.reload()
JEH.apply()
```

Entries added by scripts are noted `kubejs(unsaved)` (not written yet) or `kubejs(saved)`.
Scripts re-run on every launch; to let a script fully own the list, `JEH.clear()` first to avoid
accumulating across launches.

## Building from source

Requires JDK 17. Windows:

```powershell
.\gradlew.bat build        # output: build\libs\justenoughhiding-<version>.jar
.\gradlew.bat runData      # smoke test
```

Optional flags: `-PnoJei`, `-PnoKubeJS`, `-PnoEmi` skip the corresponding dependency.
